# CI0006: Collection initializer is used without capacity

Using a collection initializer on `List<T>` without specifying an initial capacity (or specifying a capacity smaller than the count of initialized items) harms performance by causing repeated memory allocations and array resizes as elements are added.

## Code Fixes
- **Set initial capacity**: Automatically calculates the number of elements in the collection initializer and passes it to the `List<T>` constructor.

## Examples

### Violation: capacity is not specified
```csharp
var list = new List<int> { 1, 2, 3, 4 };
```

#### Fix
```csharp
var list = new List<int>(4) { 1, 2, 3, 4 };
```

### Violation: capacity is smaller than number of initialized elements
```csharp
var list = new List<string>(2) { "1", "2", "3", "4" };
```

#### Fix
```csharp
var list = new List<string>(4) { "1", "2", "3", "4" };
```

> **Note**: For C# 12+ collection expressions (`List<int> list = [1, 2, 3, 4];`), the C# compiler automatically allocates the exact required capacity, so no warning is emitted.
