# CI0008: Consider using HashSet instead of an array for Contains operations

An array is used with the LINQ `Contains()` method for lookup operations. Arrays perform linear search with $O(N)$ time complexity, which can become a performance bottleneck when the array contains multiple elements or when lookups are executed frequently.

Replacing the array with `HashSet<T>` or `FrozenSet<T>` provides $O(1)$ constant-time lookup performance.

## Configuration
You can configure the minimum number of items in the array required to trigger the diagnostic. Default value is `1`.

In `.editorconfig`:
```ini
dotnet_diagnostic.CI0008.min_items_count = 5
```

## Code Fixes
- **Replace array with HashSet**: Replaces array declaration with `HashSet<T>` for $O(1)$ lookups. Supports array creation expressions (`new[] { ... }`, `new int[] { ... }`), array initializers (`{ ... }`), and C# 12 collection expressions (`[ ... ]`).
- **Replace array with FrozenSet**: (Available on .NET 8+ when `System.Collections.Frozen` is referenced) Replaces array with immutable `FrozenSet<T>` (`ToFrozenSet()`). `FrozenSet<T>` is optimized for read-only lookups, offering faster lookup speeds and smaller memory footprint than `HashSet<T>`. Supports spread elements (`[..other, ...]`) as well.

## Examples

### Examples of Violations

```csharp
public class ArrayContains
{
    // C# 12+ collection expression syntax
    public int[] ListCollectionExpr { get; } = [1, 2, 3, 4];

    public int[] List3 { get; } = new[] { 1, 2, 3, 4 };

    private readonly int[] _list2 = { 1, 2, 3, 4 };

    public bool Method1()
    {
        var list1 = new[] { 1, 2, 3, 4 };
        return list1.Contains(5);
    }

    public bool Method2()
    {
        return _list2.Contains(5);
    }

    public bool Method3()
    {
        return List3.Contains(5);
    }

    public bool Method4()
    {
        var list = new int[] { 1, 2, 3, 4 };
        return list.Contains(2);
    }

    public bool Method5()
    {
        int[] numbers = [1, 2, 3, 4, 5];
        return numbers.Contains(3);
    }
}
```

### Code Fix: Replace with HashSet

```csharp
using System.Collections.Generic;

public class ArrayContains
{
    public HashSet<int> ListCollectionExpr { get; } = [1, 2, 3, 4];

    public HashSet<int> List3 { get; } = new HashSet<int> { 1, 2, 3, 4 };

    private readonly HashSet<int> _list2 = new HashSet<int> { 1, 2, 3, 4 };

    public bool Method1()
    {
        var list1 = new HashSet<int> { 1, 2, 3, 4 };
        return list1.Contains(5);
    }

    public bool Method5()
    {
        HashSet<int> numbers = [1, 2, 3, 4, 5];
        return numbers.Contains(3);
    }
}
```

### Code Fix: Replace with FrozenSet (.NET 8+)

```csharp
using System.Collections.Frozen;

public class ArrayContains
{
    public FrozenSet<int> ListCollectionExpr { get; } = new[] { 1, 2, 3, 4 }.ToFrozenSet();

    public FrozenSet<int> List3 { get; } = new[] { 1, 2, 3, 4 }.ToFrozenSet();

    private readonly FrozenSet<int> _list2 = new[] { 1, 2, 3, 4 }.ToFrozenSet();

    public bool Method1()
    {
        var list1 = new[] { 1, 2, 3, 4 }.ToFrozenSet();
        return list1.Contains(5);
    }

    public bool Method5()
    {
        FrozenSet<int> numbers = new[] { 1, 2, 3, 4, 5 }.ToFrozenSet();
        return numbers.Contains(3);
    }
}
```
